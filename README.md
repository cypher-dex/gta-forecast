An analog-ensemble forecast of GTA VI's launch-day Twitch viewers. For every past launch in the case's comparables it takes the log ratio of each hour of release day to hour 1, weights the launches by how well their unlock timing, platforms and hour-1 size match, and turns the weighted ratios into five quantiles per hour with a spread that widens through the day.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
